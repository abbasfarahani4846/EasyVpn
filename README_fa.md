# EasyVpn

یک کلاینت ساده‌ی «یک‌کلیکی» برای **ویندوز، اندروید و لینوکس** بر پایه‌ی هسته‌ی
[mihomo](https://github.com/MetaCubeX/mihomo)، ساخته‌شده برای شبکه‌هایی که سرورها مدام
فیلتر می‌شوند. [English](README.md)

## امکانات

- **هر چیزی را بچسبانید.** لینک‌های اشتراکی (`vless://`، `vmess://`، `trojan://`، `ss://`،
  `hy2://`، `tuic://`، `anytls://`)، لینک اشتراک، فایل YAML کلش/میهومو یا JSON پروکسی؛
  سرورها اضافه می‌شوند. لینک‌های XHTTP همه‌ی تنظیماتشان را (padding، XMUX، download settings) نگه می‌دارند.
- **تعمیر خودکار پورت.** سروری که روی پورت خودش جواب نمی‌دهد روی پورت جایگزین تست و اصلاح
  می‌شود؛ اگر روی هیچ‌کدام جواب نداد، به‌جای رها شدن، خطا گزارش می‌شود.
- **عبور مستقیم کشور.** ترافیک بازه‌های IP و دامنه‌های یک کشور (ایران و چندین کشور دیگر)
  مستقیم می‌رود؛ لیست‌ها یک بار دانلود و روی دستگاه نگه‌داری می‌شوند.
- **اتصال با یک ضربه** و داشبوردی که IP واقعی خروجی و مسیر استفاده‌شده را نشان می‌دهد.
- ابزارهای **سرور ورودی (Chain)**، **Psiphon**، **Windscribe** و **WARP** داخل برنامه.
- **آپدیت داخل برنامه.** صفحه‌ی اصلی وقتی نسخه‌ی جدید هست خبر می‌دهد و نصبش می‌کند.
